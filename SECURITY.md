# Security

THE WALL runs on a small private server, and anyone can host their own copy. If you find a vulnerability in the server, the website or the firmware, please report it privately instead of opening a public issue.

- On GitHub: the **Security** tab of this repository, then **Report a vulnerability**.
- Otherwise: the contact address on the legal notice of the hosted instance, https://thewall.godart.lu/legal#imprint

Please include what you found, how to reproduce it, and which version or commit you tested. There is no bug bounty, this is a hobby project.

Known and intended: the setup network `THE WALL SETUP` has a fixed password. The panel shows it as text, and the network is only meant to be up while a device is being set up.
